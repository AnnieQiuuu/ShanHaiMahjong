# 全地区试玩与元素反馈更新

日期：2026-11-01

## 已完成

八地区现在全部直接开放，不需要修改或清除原有收藏存档。关卡选择框可直接进入中州至天界。后续若要恢复线性解锁，可在主控制器Inspector关闭all_regions_unlocked；真实通关进度仍单独保留。

五行结算增加约0.65秒的目标预告与短效果，之后刷新棋盘并闪亮新可用牌。火为爆点、风为风线与目标滑出、水为水波与解放、雷为折线电弧、土为护佑印记。期间禁止配对、撤回、洗牌和暂停，允许重开；重开会取消旧动画后续刷新，避免旧操作污染新局。Combo和手动移除后的数量会立即更新。无合适目标时仍可看到对应的状态说明。

死局弹窗区分：可洗牌恢复、重排资源耗尽、没有同种伙伴、可用牌位不足。弹窗提供可用的洗牌、撤回、重开及查看棋盘操作；无法救回时不会浪费洗牌次数。

种子、测试局、日志路径和元素开关已收入右下角“测试工具”，默认收起，也可按F1。关闭元素只对独立测试局有效，对正式地区无效。

火与风仍然单张移除。目标评分现在优先清掉已有孤牌，尽量避开会破坏最后一对的目标；没有更安全目标时仍允许风险操作，不承诺避免所有死局。保护未发现宠物的规则保留。

## 新增对照结果

| 测试局 | 条件 | 操作及结果 |
|---|---|---|
| 水开路，6张 | 元素开启、无洗牌 | 水→火→风，三次手动配对清空 |
| 同一水局 | 元素关闭、无洗牌 | 消水后剩4张，火与风的伙伴互相受阻，失败 |
| 土护佑救局，6张 | 元素开启、普通洗牌0次 | 消土获得1护佑；死局用护佑重排，再消两对，清空 |
| 同一土局 | 元素关闭、普通洗牌0次 | 消土后没有护佑，剩4张且无合法对子，失败 |

两局都固定相同初始牌面与种子20261101，对照时只切换元素开关。水局一开始只有水对子可选，土局一开始只有土对子可选，因此开关造成的差异发生在对应元素第一次结算。

这证明两个小局中元素能改变胜负。土局验证的是基础护佑的实际用途，不是高Combo的额外护佑是否必要。先前的土Combo局仍是11点与9点护佑对照，两条路线都能清空，不能据此声称×5具有必胜策略价值。

完整机器证据在PLAYTEST_RESULTS.json：14条脚本案例、41步记录，读取实际JSON逐步重播验证。包含原10条和本次4条新对照，不是随机独立牌局抽样，不能用来推断总体胜率。

数量足够不等于某局一定存在连续五次同元素的合法顺序；这仍需含元素效果的路径验证。初始生成测试继续只证明忽略技能时有完整配对解法，不应解读为强制技能结算下每局必有解。

## 试玩方式

F5启动后直接选任一地区。右下角“测试工具”内可进入五个测试局。水开路与土护佑救局可勾选“关闭元素”比较，切换开关会重开当前测试局。重开保留种子输入，正式收藏不受测试局影响。
