# 山海麻将 — Godot 可维护原型 v0.2.1

本项目使用 Godot 4.3+ / GDScript。打开 `project.godot` 后按 F6/F5 运行。

## 已实现

- 36 张牌，三层堆叠（24 + 8 + 4）。
- 使用原始 14 张宠物 PNG 中随机选出的 9 种，每种 4 张。
- 使用手绘 V2 麻将牌体 PNG，宠物贴图与牌体在运行时独立绘制。
- 经典上海麻将规则：上方无遮挡，且左右至少一边开放。
- 选中高亮、两张相同牌配对、移除、胜利判定。
- 牌阵沿一条合法的完全消除路径生成，确保初始状态至少有一条解法。
- 调试快捷键：`R` 重开，`Z` 撤销一对，`H` 提示一对。

## 当前刻意未实现

五行技能、Combo、关卡地图、图鉴、正式 UI/音效、触屏布局优化以及高级消除动画均在后续迭代。

## 开发注意

核心逻辑已按责任拆分，详见 `docs/ARCHITECTURE.md`。AI 开发规则在 `AGENTS.md`，美术标准在 `docs/ART_STYLE_GUIDE.md`。

在 Godot 中打开 `scenes/tile_view.tscn`，可通过 Inspector 调整卡牌贴图区域、选中描边和遮挡透明度。打开 `scenes/board_view.tscn` 可调整间距和叠层偏移（请让两处卡牌尺寸保持一致）。背景及 HUD 位于 `scenes/main.tscn`。

已使用官方 Godot 4.3 在无画面模式完成项目解析、主场景启动，以及自动化规则和交互测试。正式画面与鼠标手感仍需在本地打开编辑器按 F5 确认。

如果安装了 Godot 命令行，也可以运行 `godot --headless --path . --script res://tests/test_board.gd`，执行 50 个种子牌局及基本遮挡判定的冒烟测试。

另有 `godot --headless --path . --script res://tests/test_game.gd`，用于测试场景载入、配对、撤销与重新开始。

初始牌局有解不代表玩家的任意消除顺序都有解。这个原型保留了经典上海麻将的死局可能性，后续应加入完整死局检测和重排规则。
