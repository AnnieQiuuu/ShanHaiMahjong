# 山海麻将 — Godot 可玩原型 v0.1

本项目使用 Godot 4.3+ / GDScript。打开 `project.godot` 后按 F6/F5 运行。

## 已实现

- 36 张牌，三层堆叠（24 + 8 + 4）。
- 使用原始 14 张宠物 PNG 中随机选出的 9 种，每种 4 张。
- 使用手绘 V2 麻将牌体 PNG，宠物贴图与牌体在运行时独立绘制。
- 经典上海麻将规则：上方无遮挡，且左右至少一边开放。
- 选中高亮、两张相同牌配对、移除、胜利判定。
- 牌阵沿一条合法的完全消除路径生成，确保初始状态至少有一条解法。
- 调试快捷键：`R` 重开，`Z` 撤销一对，`H` 提示一对。

## 当前刻意未实现

五行技能、Combo、关卡地图、图鉴、正式 UI/音效、触屏布局优化以及高级消除动画均在后续迭代。

## 开发注意

`scripts/main.gd` 保存全部原型逻辑。每张牌包含层号、网格坐标、宠物 ID 和已消除状态；重新生成牌局不修改任何原始 PNG。图片尺寸会在运行时缩放。无需安装外部插件。

初始牌局有解不代表玩家的任意消除顺序都有解。这个原型保留了经典上海麻将的死局可能性，后续应加入完整死局检测和重排规则。
